# Power BI Dashboard

## Fintech Customer Behaviour & Classification Analysis

This dashboard presents an interactive exploration of customer characteristics, transaction behaviour, card ownership and billing patterns across the two customer classifications supplied in the XYZ dataset.

## Report Pages

### 1. Customer Overview
- Customer classification distribution
- Customer demographics
- Age distribution
- Gender and marital status breakdown

### 2. Customer Behaviour
- Transaction activity
- Annual transaction patterns
- Last transaction recency
- Card ownership
- Billing amounts and credit limits
- Usage percentage

### 3. Statistical Evidence
- Chi-square tests
- Mann–Whitney U tests
- Effect size measurements
- Logistic regression model comparison

### 4. Insights & Recommendations
- Key analytical findings
- Recommended business actions
- Dataset limitations

## Files

- `fintech_customer_churn.pbix` — Interactive Power BI report.
- `fintech_customer_churn.pdf` — Static PDF export.

## Important Notes

The dashboard analyses the classifications supplied in the dataset. It does not establish a verified real-world churn rate or demonstrate future churn prediction.

Statistical associations should not be interpreted as causal relationships.

For the full methodology, SQL queries, Python analysis and documentation, see the main project repository.
